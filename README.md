# QAM Modulation Simulation (QPSK, QAM16, QAM64)

## Описание

Реализация симуляции цифровой модуляции QAM (Quadrature Amplitude Modulation) на C++ с добавлением гауссовского шума (AWGN) и подсчётом вероятности ошибки на бит (BER).

Проект выполнен в рамках отбора на летнюю стажировку.

## Возможности

- Модуляция QPSK, QAM16, QAM64
- Добавление гауссовского шума к созвездию
- Демодуляция и подсчёт ошибок
- Построение графиков BER от уровня шума (σ)
- Сохранение и визуализация точек созвездия с шумом

## Требования

- C++ (g++)
- Python 3 с библиотеками: matplotlib, pandas

## Сборка и запуск

```
chmod +x run.sh
./run.sh
```
